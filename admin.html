ربط TikTok & Instagram التلقائي (Universal Webhook)

يمكنك ربط حسابك في تيك توك وإنستغرام بأي خدمة مجانية مثل IFTTT أو Make.com أو Zapier لتنبيه موقعك لحظياً بمجرد نشر أي فيديو أو بوست جديد.

طريقة الربط السريعة في دقيقتين عبر IFTTT أو Make:

  1. أنشئ حساباً مجانياً على موقع IFTTT.com أو Make.com.
  2. اختر في خانة (If This): TikTok (New video by you) أو Instagram (New photo/reel by you).
  3. اختر في خانة (Then That): Webhooks (Make a web request).
  4. الصق رابط الـ Webhook بالأعلى، واختر الطريقة: POST ونوع المحتوى: application/json.
  5. ضع في خانة Body هذا القالب: 
    {"url": "{{Url}}", "title": "{{Caption}}", "secret": "horizon_auto_2026"}
  6. اضغط حفظ! ومن الآن فصاعداً أي فيديو أو بوست ينزل سيصل فوراً للديسكورد بدون ما تفتح لوحة التحكم! 🎉

انسخ معرف الروم من الديسكورد (عبر تفعيل وضع المطور Developer Mode ثم النقر بزر الماوس الأيمن على الروم واختيار Copy Channel ID).

كيف تشغل بوت الديسكورد لأول مرة؟

  1. توجه إلى Discord Developer Portal وأنشئ تطبيقاً جديداً (New Application).
  2. انتقل لقسم Bot واضغط Reset Token لنسخ التوكن السري (Bot Token).
  3. قم بتفعيل خيارات Privileged Gateway Intents (مثل Message Content Intent).
  4. ضع التوكن في ملف .env تحت المتغير DISCORD_TOKEN.
  5. ضع الـ Client ID تحت CLIENT_ID.
  6. ادعُ البوت إلى سيرفرك بصلاحيات إرسال الرسائل والأوامر (Administrator أو Send Messages & Embed Links).
