# 🌐 Horizon Services — Official Social Media Hub & Community Portal

موقع ويب عصري، فائق الجمال والسرعة تم تصميمه خصيصاً لمجتمع **Horizon Services** وصانع المحتوى **عمر الشامي (Omar Creator)**، ومعد للنشر المباشر على منصة **Vercel** بضغطة زر واحدة بدون أي تبعيات معقدة.

---

## 🌟 مميزات الموقع:
- **تصميم دارك مود أحمر قرمزي فخم (Black & Crimson Glassmorphism)** متناسق مع هوية Horizon Services.
- **عرض المنصات الرسمية**:
  - 🔴 **YouTube**: رابط القناة + تضمين مباشر لأحدث الفيديوهات والشروحات.
  - ⚫ **TikTok**: رابط ومقاطع التيك توك.
  - 🟣 **Instagram**: حساب الإنستغرام والستوريات.
  - 🔵 **Facebook**: الصفحة الرسمية.
  - 🎮 **Discord**: بطاقة تفاعلية وحالة اتصال بوت Horizon Master وزر دخول فوري للسيرفر (`https://discord.gg/hz-s`).
- **استعراض خدمات Horizon Services**: برمجة بوتات الديسكورد والتليجرام، تطوير المواقع والمشاريع الكاملة، واستضافات السيرفرات السحابية VPS.
- **نافذة مشاركة مع رمز QR Code**: لمشاركة رابط البوابة بسهولة مع المتابعين.
- **أداء فائق وZero Downtime**: مصمم كـ Static Web Application ليعمل على شبكة Vercel العالمية بسرعة تحميل فورية وبدون أي أخطاء.

---

## 🚀 طريقة الرفع على Vercel:
1. اربط هذا المجلد بمستودع GitHub الخاص بك.
2. ادخل على [Vercel](https://vercel.com) واضغط **Add New Project**.
3. اختر المستودع واضغط **Deploy**.
4. سيعمل موقعك فوراً وبشكل دائم على دومين مجاني ينتهي بـ `.vercel.app`!
