انسخ معرف الروم من الديسكورد (عبر تفعيل وضع المطور Developer Mode ثم النقر بزر الماوس الأيمن على الروم واختيار Copy Channel ID).

كيف تشغل بوت الديسكورد لأول مرة؟

  1. توجه إلى Discord Developer Portal وأنشئ تطبيقاً جديداً (New Application).
  2. انتقل لقسم Bot واضغط Reset Token لنسخ التوكن السري (Bot Token).
  3. قم بتفعيل خيارات Privileged Gateway Intents (مثل Message Content Intent).
  4. ضع التوكن في ملف .env تحت المتغير DISCORD_TOKEN.
  5. ضع الـ Client ID تحت CLIENT_ID.
  6. ادعُ البوت إلى سيرفرك بصلاحيات إرسال الرسائل والأوامر (Administrator أو Send Messages & Embed Links).
